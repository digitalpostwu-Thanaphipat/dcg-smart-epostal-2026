## Summary

Release `@264` retires OCR from the postal entry workflow, deploys the latest GAS frontend bundle, and documents the simplified production admin operation model.

## Backend

- Removed `performOCR` from `ROLE_PERMISSIONS`.
- Removed `performOCR` from `ROUTE_MAP`.
- Kept `backend/Service_AI.gs` only as a compatibility stub.
- `Service_AI.performOCR()` now returns `OCR_RETIRED` and does not call Gemini or `UrlFetchApp`.
- Deployed delivery confirmation optimization so selected rows are written with grouped batch writes instead of cell-by-cell writes.

## Frontend

- Removed the AI/OCR parcel scan control from the postal entry page.
- Removed OCR state/handler from postal entry hook.
- Removed AI model selection from system settings.
- Removed `ApiClient.ai` OCR methods from frontend source.
- Rebuilt `backend/index.html` from the latest frontend bundle.
