# ePostal Readiness Snapshot

อัปเดต: 2026-06-30

## สถานะปัจจุบัน

- โค้ดใช้ไฟล์โปรเจกต์ `ePostal_2026` เป็นฐานหลัก
- ชีทผู้ใช้ระบบอยู่ที่ `ePostal_2026 > ผู้ใช้งานระบบ`
- บัญชีทดสอบ admin คือ `digitalpost.wu@gmail.com`
- สถานะพัสดุเหลือ 3 ค่า: `รอนำจ่าย`, `ส่งมอบแล้ว`, `มีปัญหา/ตีกลับ`
- ชื่อชีทในไฟล์โปรเจกต์เป็นภาษาไทยแล้ว
- `DCG_Central_DB` ยังใช้เฉพาะ master data จาก HR/ส่วนกลาง

## งานที่เพิ่มรอบนี้

- เพิ่มคำสั่ง backend `repairProjectSheetHeaders`
- คำสั่งนี้เขียนหัวตารางทุกชีทในไฟล์โปรเจกต์ ใส่สีหัวตาราง freeze แถวแรก ตั้งสีสถานะ และ lock หัวตารางกลับ
- `repairPackageLogHeaders` จะเรียกตัวซ่อมหัวตารางโปรเจกต์ตัวใหม่ด้วย
- ปรับ Playwright local smoke ให้ใช้ `127.0.0.1:5173` และเช็กหน้าล็อกอินด้วยข้อความที่ตรงของจริง
- เพิ่มเอกสาร `SHEET_COLUMN_GUIDE.md` สำหรับ HR/Admin

## วิธีซ่อมหัวตารางบนชีทจริง

หลัง deploy แล้ว ให้เปิดไฟล์ `ePostal_2026` แล้วใช้เมนู ePostal เดิมสำหรับจัดระเบียบ/ซ่อมหัวตาราง หรือเรียก action `repairProjectSheetHeaders` ผ่านระบบ admin

เหตุผล: หัวตารางถูก lock ไว้ถูกต้องแล้ว การซ่อมต้องให้ Apps Script ที่เป็นเจ้าของระบบเป็นคนเขียนหัวตารางก่อน lock กลับ ไม่ควรแก้มือจากบัญชีที่ไม่มีสิทธิ์ปลด protection

## ความเสี่ยงที่ยังต้องตรวจหลัง deploy

- ตรวจชีทจริงแบบ read-only แล้วเมื่อ 2026-06-30:
  - หัวตารางครบแล้ว 9/9 ชีท: `รายการพัสดุ`, `สถิติระบบ`, `ผู้ใช้งานระบบ`, `ตัวแทนรับไปรษณีย์ภัณฑ์`, `ดัชนีแฟ้มย้อนหลัง`, `ประกาศจากระบบ`, `บันทึกการใช้งาน`, `การตั้งค่าระบบ`, `บันทึกข้อเสนอแนะ`
  - `ผู้ใช้งานระบบ` มีหัวตารางครบ 6 คอลัมน์แล้ว
  - `บันทึกข้อเสนอแนะ` มีหัวตารางครบ 9 คอลัมน์แล้ว
- ต้องทดสอบ login จริงด้วย `digitalpost.wu@gmail.com`
- ต้องตรวจว่า admin เห็นข้อมูลผู้ใช้จาก `ePostal_2026 > ผู้ใช้งานระบบ`
- ต้องตรวจเพิ่ม/แก้/ลบผู้ใช้ แล้วข้อมูลลงชีทโปรเจกต์ ไม่ไปลงไฟล์กลาง

## ข้อจำกัดที่ตรวจพบ

- Google Sheets API ด้วย service account อ่านชีทได้ แต่แก้หัวตารางที่ถูก lock ไม่ได้
- `clasp run repairProjectSheetHeaders` ยังรันไม่ได้จากเครื่องนี้ เพราะบัญชี clasp ไม่มีสิทธิ์ run function
- ซ่อมหัวตารางจริงสำเร็จผ่าน Web App ที่ execute as deployer แล้ว จากนั้นปิด public action กลับทันทีและ redeploy final แล้ว
