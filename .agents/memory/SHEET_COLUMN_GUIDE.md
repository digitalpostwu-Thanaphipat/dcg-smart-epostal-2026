# ePostal: คู่มือชีทและคอลัมน์ปัจจุบัน

อัปเดต: 2026-06-30

## หลักสำคัญ

- ไฟล์โปรเจกต์หลักคือ `ePostal_2026`
- ผู้ใช้งานระบบย้ายมาอยู่ที่ `ePostal_2026 > ผู้ใช้งานระบบ`
- `ตัวแทนรับไปรษณีย์ภัณฑ์` อยู่ในไฟล์โปรเจกต์ `ePostal_2026` เพื่อให้ Admin ดูแลร่วมกับงานไปรษณีย์ได้ที่เดียว
- `DCG_Central_DB` ยังใช้สำหรับข้อมูลกลางจาก HR/หน่วยงาน เช่น หน่วยงาน พนักงาน และตำแหน่ง
- โค้ดพยายามอ่านจากชื่อหัวคอลัมน์ก่อน ถ้าหาไม่เจอจะ fallback ไปอ่านตามลำดับคอลัมน์เดิม
- แถวหัวตารางต้องอยู่แถว 1 และระบบจะ lock หัวตารางไว้กันแก้พลาด

## ชีทใน `ePostal_2026`

### `รายการพัสดุ`

ใช้เก็บรายการรับ-ส่งพัสดุจริง ระบบเขียนเองเป็นหลัก

ลำดับคอลัมน์:

| ลำดับ | คอลัมน์ |
| --- | --- |
| A | รหัสพัสดุ |
| B | เลขพัสดุ |
| C | ประเภท |
| D | ชื่อหน่วยงาน |
| E | ชื่อผู้รับ |
| F | สถานะ |
| G | เวลาที่บันทึก |
| H | เวลาที่จ่าย |
| I | จนท.ผู้นำจ่าย |
| J | ผู้รับจริง |
| K | ลายเซ็น |
| L | รูปภาพ |
| M | พิกัด GPS |
| N | วิธีการส่งมอบ |
| O | ประเภทการใช้ |
| P | หมายเหตุ / Line |
| Q | ผู้บันทึก |
| R | ผู้อัปเดตล่าสุด |

สถานะที่ใช้จริงมี 3 ค่าเท่านั้น:

- `รอนำจ่าย`
- `ส่งมอบแล้ว`
- `มีปัญหา/ตีกลับ`

### `ผู้ใช้งานระบบ`

ใช้กำหนดคนเข้าใช้ระบบและสิทธิ์ ระบบ login/admin อ่านจากชีทนี้

HR/Admin ต้องเตรียม:

| ลำดับ | คอลัมน์ | ต้องมีไหม |
| --- | --- | --- |
| A | รหัสพนักงาน | ควรมี |
| B | อีเมล (Google) | ต้องมี |
| C | ชื่อ-นามสกุล | ต้องมี |
| D | สิทธิ์ (Admin/User/Postal) | ต้องมี |
| E | หน่วยงาน/แผนก | ควรมี |
| F | ตำแหน่ง | ควรมี |

โค้ดอ่านจากชื่อคอลัมน์ก่อน เช่น `อีเมล`, `อีเมล (Google)`, `ชื่อ-นามสกุล`, `สิทธิ์`, `หน่วยงาน/แผนก` ถ้าหัวตารางหายจะ fallback เป็น B=email, C=name, D=role, E=department

### `ตัวแทนรับไปรษณีย์ภัณฑ์`

ใช้เก็บรายชื่อตัวแทนของแต่ละหน่วยงานที่รับ/ตรวจสอบไปรษณีย์ภัณฑ์แทนบุคลากรในหน่วยงาน

ตำแหน่งจริง: `ePostal_2026 > ตัวแทนรับไปรษณีย์ภัณฑ์`

| ลำดับ | คอลัมน์ | ใช้ทำอะไร |
| --- | --- | --- |
| A | อีเมล | อีเมล Google ของตัวแทน |
| B | ชื่อ-นามสกุล | ชื่อเต็มของตัวแทน |
| C | รหัสหน่วยงาน | ใช้ผูกตัวแทนกับหน่วยงาน |
| D | ชื่อหน่วยงาน | ชื่อหน่วยงานแบบอ่านง่าย |
| E | สถานะ | `ใช้งาน` หรือ `ระงับ` |
| F | เบอร์โทร | ช่องทางติดต่อ |
| G | Line ID | ช่องทางติดต่อเพิ่มเติม |
| H | หมายเหตุ | เช่น ตัวแทนหลัก/สำรอง |
| I | อัปเดตล่าสุด | วันที่แก้ไขข้อมูลล่าสุด |

ระบบยังอ่านชื่อชีทเดิม `ตัวแทนรับพัสดุ` ได้ชั่วคราว แต่ชื่อที่ควรใช้ต่อไปคือ `ตัวแทนรับไปรษณีย์ภัณฑ์`

## ชีทที่ต้องขอข้อมูลจาก HR/ส่วนกลางใน `DCG_Central_DB`

### `รายชื่อหน่วยงาน`

ใช้ทำ dropdown หน่วยงาน และแสดงอาคาร/ชั้น

ต้องขอ:

| คอลัมน์แนะนำ | ใช้ทำอะไร |
| --- | --- |
| รหัสหน่วยงาน | รหัสอ้างอิง |
| ชื่อหน่วยงาน | ชื่อที่แสดงในระบบ |
| อาคาร | แสดง/จัดกลุ่มงานนำจ่าย |
| ชั้น | แสดงตำแหน่งหน่วยงาน |

โค้ดอ่านจากชื่อคอลัมน์ก่อน ถ้าไม่เจอจะอ่าน A=รหัส, B=ชื่อ, C=อาคาร, D=ชั้น

### `รายชื่อพนักงาน`

ใช้เลือกผู้รับพัสดุ

ต้องขอ:

| คอลัมน์แนะนำ | ใช้ทำอะไร |
| --- | --- |
| อีเมล | ระบุตัวบุคคล |
| ชื่อ-นามสกุล | ชื่อผู้รับ |
| รหัสหน่วยงาน | ผูกกับหน่วยงาน |

โค้ดอ่านจากชื่อคอลัมน์ก่อน ถ้าไม่เจอจะอ่าน A=อีเมล, B=ชื่อ, C=รหัสหน่วยงาน

### `รายชื่อตำแหน่งบริหาร`

ใช้ข้อมูลตำแหน่งประกอบรายงาน/งานส่งมอบพิเศษ

ต้องขอ:

| คอลัมน์แนะนำ | ใช้ทำอะไร |
| --- | --- |
| รหัสหน่วยงาน | ผูกกับหน่วยงาน |
| ชื่อตำแหน่ง | ชื่อตำแหน่ง |

โค้ดอ่านจากชื่อคอลัมน์ก่อน ถ้าไม่เจอจะอ่าน A=รหัสหน่วยงาน, B=ชื่อตำแหน่ง
