#  ePostal System Memory (Long-term Knowledge)

โฟลเดอร์นี้ใช้สำหรับจัดเก็บ "ความจำระยะยาว" ของโปรเจกต์ เพื่อให้สกิล `epostal-brain` นำไปใช้อ้างอิงบริบท (Context) ของการตัดสินใจในอดีต ป้องกันไม่ให้ AI หรือนักพัฒนาคนใหม่รื้อโค้ดที่เคยตกลงกันไว้แล้ว

## 📂 โครงสร้างการจัดเก็บ
แนะนำให้แยกไฟล์เป็นหมวดหมู่ดังนี้ (AI จะเป็นผู้สร้างและอัปเดตไฟล์เหล่านี้ให้เองเมื่อสั่งงานผ่าน Step 6 ของ Workflow):

*   `adr-xxx.md` (Architecture Decision Records) - เก็บประวัติการตัดสินใจเรื่องโครงสร้างระบบ
*   `known-bugs.md` - ประวัติบั๊กที่แก้ชั่วคราว หรือต้องเฝ้าระวัง
*   `data-flow.md` - บันทึกทิศทางการไหลของข้อมูลที่ซับซ้อน
