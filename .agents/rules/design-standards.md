# Rule: Nexus Soft Design Standards

## 🎨 Hero Pattern
- ทุกหน้าหลักต้องมี Banner ด้านบน (Hero Section)
- พื้นหลัง Banner: `Zinc-900`
- เอฟเฟกต์: ต้องมีไอคอนจางๆ (Subtle Icons) เป็น Background และมี Zap Badge

## 📦 Package Cards
- รูปร่าง: `rounded-2xl`
- ส่วนประกอบ:
  - ไอคอนพัสดุที่มุมซ้ายบน
  - ข้อมูลพัสดุตรงกลาง
  - เลขพัสดุ (Tracking ID) อยู่ด้านล่างสุด แยกด้วยเส้น `border-t`

## 🔤 Typography
- **Heading:** ใช้ Font `Prompt`
- **Body:** ใช้ Font `Sarabun`
- **Rule:** ห้ามใช้ Font อื่นนอกเหนือจากที่กำหนด
