ติดตั้ง DCG Smart ePostal

Install on PC & Smartphone — ติดตั้งบนคอมพิวเตอร์และสมาร์ทโฟน

คอมพิวเตอร์ (PC / Laptop)
🔒 script.google.com/macros/s/.../exec
⋮ เมนู Chrome → "ติดตั้ง DCG Smart ePostal"
  1. 1เปิด Google Chrome แล้วเข้า Production URL
  2. 2กดปุ่ม ⋮ (Three Dots) ที่มุมบนขวา
  3. 3เลือก "ติดตั้ง DCG Smart ePostal" หรือ "Install DCG Smart ePostal"
  4. 4ยืนยันการติดตั้ง → ไอคอนจะปรากฏบน Desktop
สมาร์ทโฟน (Android / iOS)
🔒 script.google.com/macros/s/.../exec
📱 เพิ่มลงหน้าจอหลัก → "ติดตั้งแอป"
  1. 1เปิด Google Chrome บนมือถือ แล้วเข้า Production URL
  2. 2กดปุ่ม ⋮ (Three Dots) หรือ Share icon
  3. 3เลือก "เพิ่มลงหน้าจอหลัก" หรือ "Add to Home Screen"
  4. 4ยืนยัน → ไอคอนจะปรากฏบน Home Screen
